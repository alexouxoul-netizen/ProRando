# Catalogues complémentaires — V11.5

Les droits de reprise automatique ne sont pas établis pour ces catalogues. RandoVista affiche leurs liens et permet l’import d’un GPX téléchargé selon leurs conditions. Aucun de leurs catalogues, photos ou traces n’est copié dans la livraison.

Ariège :
- Ariège Pyrénées Tourisme : https://www.ariegepyrenees.com/preparer/randonner/ — https://www.ariegepyrenees.com/mentions-legales/
- FFRandonnée Ariège / MaRando : https://cdrp09.com/nos-pr-promenade-randonnee/ — plus de 60 itinéraires annoncés par le comité ; accès soumis aux conditions MaRando.
- TraceRando : https://tracerando.jimdofree.com/randonn%C3%A9e-montagne/randonn%C3%A9e-en-ariege-gps-gpx-kml/ — catalogue d’auteur, traces parfois anciennes ; aucune licence générale GPX établie.
- MapiRando Couserans : https://www.mapirando.fr/randonnee-couserans/ — sélection d’auteur ; droits de redistribution non établis.

Haute-Garonne :
- Geotrek Pyrénées Haut-Garonnaises : https://rando.cc-pyreneeshautgaronnaises.fr/ — 52 fiches françaises pédestres publiées avec GPX ; API https://admin-ccphg.openig.org/api/v2/ ; licence de reprise non établie.
- Pyrénées31 : https://www.pyrenees31.com/randonnees
- Peyragudes (31/65) : https://peyragudes.com/randonnees-trail/
- Mairie de Lherm : https://www.mairie-lherm.fr/decouvrir/se-promener/ — quatre boucles locales avec GPX annoncées.

Hautes-Pyrénées :
- Rando Vallées de Gavarnie : https://rando.valleesdegavarnie.com/ — API https://geotrek65admin.openig.org/api/v2/ ; 329 fiches françaises pédestres publiées avec lien GPX ; licence de reprise non établie.
- Vallée du Louron : https://www.vallee-du-louron.com/fr/sentiers-de-randonnees — redirections vers Louron Bike & Trail, compte possible.
- Peyragudes (31/65), ci-dessus.

Cela représente dix catalogues distincts, Peyragudes apparaissant dans deux départements. Les accès et conditions peuvent changer ; la présence d’un lien ne certifie ni la licence de reprise ni la praticabilité. La correspondance entre fichier importé et fiche reste à vérifier par l’utilisateur. Aucun verdict GPX avant import d’un fichier valide.
