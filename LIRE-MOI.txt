RandoVista V11.3.1 TEST — renommage et notes détaillées

1. Exporter une sauvegarde complète et conserver le ZIP V11.3 validé.
2. Extraire ce ZIP et déposer son CONTENU à la racine du dépôt GitHub Pages habituel, puis valider manuellement les fichiers. Conserver la même adresse et les données du navigateur.
3. Fermer les autres onglets RandoVista, rouvrir et vérifier « V11.3.1 TEST ». Vérifier que le mode hors connexion est prêt.
4. Mes randos > Renommer : saisir le nouveau nom puis « Enregistrer le nom ». « Annuler » conserve le nom précédent. Limite : 200 caractères. Le nom reste enregistré hors connexion ; le GPX, les favoris et les liens avec le carnet sont conservés. Le titre du parcours actuellement préparé est aussi actualisé s’il correspond.
5. Le filtre Note physique affiche : 1/5 — Très facile ; 2/5 — Modérée ; 3/5 — Soutenue ; 4/5 — Difficile ; 5/5 — Très difficile.

Les anciennes évaluations conservent leur intitulé historique, leur ressenti et leur association au GPX. Le nom du fichier GPX d’origine et son contenu ne sont pas réécrits. Les sauvegardes suivantes de la bibliothèque contiennent le nouveau nom.
Le renommage utilise le mécanisme de modification de bibliothèque V11 existant : les modules de synchronisation sont conservés. La transmission effective vers un autre appareil se vérifie avec votre compte partagé.
Retour arrière : republier le contenu du ZIP V11.3 conservé à la même adresse, fermer puis rouvrir l’application ; les noms enregistrés restent des données compatibles. Ne pas effacer les données du navigateur.
Aucune publication automatique.
