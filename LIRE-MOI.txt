RandoVista V11.5 TEST — Découvrir dans les Pyrénées

Aucune publication automatique.

INSTALLER
1. Exporte une sauvegarde complète depuis RandoVista. Conserve ton ZIP V11.4.1 pour revenir en arrière.
2. Extrais ce ZIP. Remplace les fichiers du dépôt GitHub habituel par son CONTENU : index.html à la racine, dossier discover-data conservé. Publie/valide ces fichiers toi-même. Garde la même adresse et la configuration cloud. Ne dépose pas le ZIP seul dans le dépôt.
3. Ferme tous les onglets RandoVista puis rouvre avec Internet. Vérifie V11.5 TEST et « Application prête hors connexion » dans Mon compte et mes sauvegardes. Attends la préparation avant de couper le réseau. N’efface pas les données du navigateur.

ESSAYER
4. Découvrir > Rechercher des randonnées. Choisis Foix, Auzat, Couserans, Ax-les-Thermes, Donezan, Luchon ou Cauterets. Tu peux aussi chercher une commune puis la sélectionner. Règle le rayon, la distance, le paysage et le profil ; touche Rechercher.
5. Pour limiter strictement la distance, décoche « Inclure les distances non renseignées ». Les filtres travaillent sur la distance annoncée par la source ; la distance réelle apparaît après analyse du GPX.
6. Récupérer et analyser le GPX, puis Ouvrir dans Préparer ou Sauvegarder dans Mes randos. Sans trace exploitable, la fiche indique la limite et ne donne aucun verdict GPX. « Uniquement les fiches avec un tracé » réduit la liste aux GPX disponibles dans cette édition.
7. Autres catalogues et import GPX donne accès à dix sources locales. Télécharge leur GPX selon les conditions du site, enregistre-le dans Fichiers sur iPhone, puis importe-le ici.
8. Vérifie tes randos, profils et données existants, puis l’arrivée d’un GPX sauvegardé sur ton second appareil avec le compte partagé. Ce dernier contrôle doit être fait avec ton compte ; il n’a pas été réalisé pendant le développement.

CE QUE CONTIENT CETTE VERSION
657 fiches Camptocamp : Ariège 197, Haute-Garonne 49, Hautes-Pyrénées 411.
190 traces passent les contrôles d’import : Ariège 28, Haute-Garonne 9, Hautes-Pyrénées 153.
Écrins et Nature64 restent disponibles dans Source et couverture.

Le catalogue Pyrénées est une édition du 12 novembre 2026, fournie dans le ZIP. Il fonctionne hors connexion après préparation, avec ses GPX. « Recharger le catalogue » relit cette édition ; une mise à jour du contenu exige une nouvelle livraison. La recherche de commune, les fonds de carte et les sites sources nécessitent Internet.

Les itinéraires sont communautaires et peuvent être anciens, dessinés, partiels ou transfrontaliers. Les nombres comptent des fiches et variantes. Le département correspond au point de référence, qui peut être un sommet. Le verdict porte uniquement sur le GPX ; consulte la fiche pour les passages techniques et conditions actuelles. Les paysages sont indicatifs. La présence d’une trace ne certifie pas le terrain.

RETOUR ARRIÈRE
Remets le contenu du ZIP V11.4.1 à la même adresse puis ferme et rouvre l’application. Ne supprime ni les données du navigateur ni le compte. Les GPX sauvegardés restent au format habituel, avec leurs métadonnées source.

Les tests et limites sont résumés dans BILAN-V11.5.md ; les sources et attributions dans SOURCES-DECOUVRIR.md et LICENCE-CATALOGUE.md. Le ZIP ne contient aucun GPX personnel utilisé pour la validation.
