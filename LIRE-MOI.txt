RandoVista V11.2 TEST — bibliothèque intelligente

1. Depuis la version actuelle, exporter une sauvegarde complète des données et conserver le ZIP V11.1 stable.
2. Extraire ce ZIP. Déposer son CONTENU à la racine du dépôt GitHub Pages habituel (index.html à la racine), puis valider les fichiers manuellement dans GitHub. Conserver cloud-config.js fourni et la même adresse de site. Ne pas effacer les données du navigateur.
3. Fermer les autres onglets RandoVista, rouvrir et vérifier « V11.2 TEST ». Dans « Mon compte et mes sauvegardes », vérifier que le mode hors connexion est prêt.
4. Dans Mes randos, choisir le profil, régler les limites de distance/D+, la note physique ou le verdict. Les filtres se combinent. Le tri par défaut privilégie les avis les plus favorables, puis le score. Les avis inconnus viennent en dernier. « Ouvrir dans Préparer » reprend le profil choisi.
5. Vérifier vos parcours, favoris, carnet et profils ; tester le mode avion après préparation du cache. Sur les deux appareils, vérifier la synchronisation V11 avec une modification de test réversible avant d’adopter cette version.

Retour : republier le contenu du ZIP V11.1 conservé à la même adresse, fermer puis rouvrir l’application. Aucun nouveau schéma de données n’est introduit. Les fonds de carte nécessitent toujours le réseau.

Aucune publication automatique. Cette archive ne contient ni vos GPX de référence, ni des données de compte, ni une bibliothèque préremplie.
