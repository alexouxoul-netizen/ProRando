RandoVista V11.4.1 TEST — Catalogues locaux 09 / 31 / 65

Rien n'est publié automatiquement.

1. Exporte une sauvegarde complète et conserve ton ZIP V11.4 pour revenir en arrière.
2. Extrais le ZIP V11.4.1. Dépose son CONTENU à la racine de ton dépôt GitHub habituel et valide les fichiers toi-même. index.html doit rester à la racine. Garde la même adresse et la configuration cloud.
3. Ferme tous les onglets RandoVista, puis rouvre avec Internet. Vérifie « V11.4.1 TEST » et l'état prêt hors connexion dans le panneau compte/sauvegardes. N'efface pas les données du navigateur.
4. Découvrir > Catalogues locaux > choisis le département. Ouvre un catalogue, recherche ta randonnée sur son site et télécharge le GPX. Un compte peut être demandé. Sur iPhone, enregistre le fichier dans Fichiers.
5. Reviens dans RandoVista et touche « J'ai téléchargé un GPX » sur le bon catalogue. Sélectionne le fichier, le profil et le nom à conserver. Vérifie l'analyse puis utilise Ouvrir dans Préparer ou Sauvegarder dans Mes randos.
6. Vérifie sur ton second appareil que le GPX sauvegardé arrive avec ton compte partagé. Ce contrôle réel n'a pas été réalisé avec ton compte pendant le développement.

Six adresses : Ariège Pyrénées Tourisme, Pyrénées 31, Rando Vallées de Gavarnie, Vallée du Louron, Peyragudes, Mairie de Lherm.

Il s'agit d'accès aux catalogues EXTERNES, pas de leurs randonnées recopiées dans RandoVista. La recherche de parcours se fait chez les producteurs. Les filtres de rayon/distance/paysage du mode Recherche intégrée ne s'appliquent pas à cet annuaire. La recherche intégrée du 64 et des Écrins est conservée dans son propre mode.

Sans GPX valide, aucun score. La correspondance du fichier avec une fiche n'est pas certifiée. Le verdict porte sur le fichier réel : deux GPX pour un même lieu peuvent donner des résultats différents. La source déclarée dans le formulaire n'est pas ajoutée au format synchronisé ; conserve son lien si tu souhaites le retrouver ensuite.

Les GPX sauvegardés restent disponibles dans Mes randos hors connexion. Les fichiers seulement analysés dans le formulaire disparaissent à la fermeture. Les sites externes nécessitent Internet. Moteur, calibration, profils, carnet, données et modules cloud sont conservés.

Retour arrière : remets le contenu du ZIP V11.4 à la même adresse, ferme et rouvre. Les GPX sauvegardés restent compatibles. Ne supprime pas les données du navigateur ni le compte.

Tests facultatifs avec Node :
node validation/test-local-catalogues.cjs
node validation/test-discover.cjs
node validation/test-release.cjs

Les GPX personnels et les fichiers téléchargés pour les tests sont exclus du ZIP publiable. Les droits et limites sont détaillés dans SOURCES-LOCALES.md.
