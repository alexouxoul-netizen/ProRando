RandoVista V11.3 TEST — niveau 1/5 Très facile

1. Exporter une sauvegarde complète des données et conserver le ZIP V11.2 validé.
2. Extraire cette archive et placer son CONTENU à la racine du dépôt GitHub Pages habituel. Valider manuellement les fichiers. Conserver la même adresse et les données du navigateur.
3. Fermer les autres onglets RandoVista, rouvrir et vérifier V11.3 TEST. Vérifier que le mode hors connexion est prêt.
4. Dans Mes randos, choisir « Note physique : 1/5 — Très facile ». Dans « Avis pour ce profil », le filtre « Très facile · 1/5 » permet de ne garder que les parcours faciles et favorables pour le profil choisi, avec des données suffisantes.
5. Ouvrir un parcours doux dans Préparer : la note physique porte le nom Très facile ; le verdict peut afficher « Très facile · 1/5 — adaptée à ce profil ». Dans Évaluer, le curseur descend à « 1/5 — Très facile ».

Le 1/5 est attribué depuis le relief mesuré, sans exception liée au nom d’une randonnée. Les seuils physiques et les scores personnalisés validés sont conservés ; l’option 1/5 du filtre est réparée et le verdict distingue désormais cette catégorie.
Un parcours 2/5 adapté à un expert reste 2/5. Un parcours aux altitudes insuffisantes n’est pas classé facile par défaut. Le verdict très facile nécessite aussi une trace complète et suffisamment détaillée, aucune pente raide notable détectée et aucun retour de vigilance pour ce profil.
L’ancienne note déclarée visant spécifiquement Gaube est retirée de cette livraison. Si le dépôt contient encore declared-route-notes.js d’une V11.2.1, ce fichier n’est plus chargé ; il peut être retiré manuellement. Remplacer notamment boot-v11.js, index.html et sw.js avec ceux de cette archive.
